你的反馈会直接进入下一轮开发计划。只记录局数与胜负,不含任何个人信息。


怎么玩

在画布任意处按住、向后拖动(像拉弹弓),松手投掷!拖动时雪人旁边会跳出角度 / 力度 %的小气泡(它会自动挑一个不挡住弹道虚线的位置站),皮筋颜色 蓝→黄→橙→红 = 力度由轻到满;力度不到 22% 松手不出手(防误触)。做完动作后回合自动交替。拉到一半不想投了?拖回起点松手,或按 Esc,都能取消这一发。

⌨️ 键盘操作(电脑):↑↓ 调角度,按住空格蓄力,松开投掷。力度条上那道浅色刻度是你上一发的力度 —— 照着它微调,比凭感觉试快得多。

🌬 顶部箭头是风向;💥 雪球会炸出雪坑,可以轰山开路。

📏 怎么算这一发:先看「距离 N 距」(一屏 = 20 距),再看风修正(顺风 +、逆风 −)。同样的距离用同样的力度,风修正只调角度 —— 打几局你就有自己的一套手感表了。

🎯 命中分三档,看画面听声音就知道打得好不好:直击(正中)= 画面顿一下 + 重震 + 闪光冲击波 + 脆响;溅射(旁边蹭到)= 中震 + 贴地环 + 闷响;落空 = 轻轻一扑 + 一声轻"噗"。被打中的一方血条会先留一截红再被追上,那截红就是这一发扣掉的血。觉得晃可到 ⚙ 设置关掉震动与残影。

左下角切换弹药:💥 雪崩罐溅射最大,🐇 三只兔一次三发,🧱 速冻砖不挖坑、反而在落点堆起一道 54px 高的雪墙——挡住对方的走位,或者落在自己身前当掩体(直击只有 12 伤,它不是用来打人的)。单人模式消耗你的库存,用积分去商店补货!

⚖️ 没有哪种弹药是"最强"的(v0.11.22 平衡带,雪崩罐直击 32 已低于手搓球 38):打得准用手搓球,打不准用雪崩罐,对手在走位用三只兔,想堵路用速冻砖。每种弹药各有名字梗 / 出场白 / 出手声,但威力当量(按钮说明里有数字)都卡在手搓球的 0.80~1.55 倍内。

👣 右下角 ◀ ▶ 走位(键盘 A/D 也行):每回合能走多远由体温决定(裸装 240,角色不同数字不同),右下角和雪人头顶都会显示还剩多少。躲出雪坑、找射角;太陡的坡爬不上去。

📦 补给箱会随机空投:打中它或走过去都能拿——热可可回血,弹药只在本局有效。

🧊 底部新增道具栏(1–7 键):花体温买这一发的强度——硬雪块加伤(同时只生效一个,再选会换掉它),连投让这回合多投几发。花得越多,下一手来得越晚。

❄ 第 20 回合起暴风雪,每回合开始冻伤 -6,别磨蹭。

🎯 打局与每日目标都给积分,连胜还有加成;积分可换弹药、围巾与帽子。

🏁 挑战关卡:10 关条件局(限次 / 狂风 / 禁特制弹 / 禁走位 / 薄血 / 早暴风雪 / 雪帝带角色),线性解锁,首通送积分和角色卡。

🎒 投手角色:打赢 AI 掉落角色卡,每个角色一个被动(加伤 / 加体温上限 / 抗风……);熔雪炉烧 2 张同阶 → 1 张高一阶。角色只能打出来,积分买不到。

🧭 走位:八种站法 —— 走完位头顶会跳出一枚徽记,这里讲清楚每种站位到底占了什么便宜(前六种能被认出来,后两种是打法,认不出来但一样管用)。

崖边 —— 站到地图两头,身后没有土,溅射就少掉近一半;代价是他一旦打过头,球出界你也没事。

坎沿 —— 地形自己的边,道理同上;而且中一发就会掉下去,他很难连着追打最疼的那两发。

独木 —— 前后都悬空,他必须算到半距以内才碰得到你;技术不细的人拿你没办法。

檐下 —— 头顶有掩体,高抛和大角度这两条路都被堵住,他只能换难打的角度。

半悬 —— 脚下那块地经不起一发;他打中你会掉下去,伤害反而不如打在实地上。

防埋 —— 看他手里那把投掷器的角度短板,站在它够不着的地方,他就打不出最疼的那一下。

创造高低差 —— 被压着打的时候别原地挨。往下爬、换个高度,让他重新算一遍;算得越多,失误越多。

地道战 —— 血少的时候往雪里挖个坑躲进去,回口气再打。管用,但别指望对手夸你。

通关翻牌:首通 2 次,重复通关 1 次;困难档更容易翻到角色卡
